# Convoy Mesh — manual ping candidate (pre-build)

**Branch:** `experiment/manual-ping-20261114`, based on the currently published pedestrian experimental app branch (PR #4). This branch is not PR #5, is not merged or published, and does not change the public APK.

**Goal:** One manually authorized synthetic connectivity event from a phone to the existing PostHog EU project. Added `ManualPingCard` to **Test log** only. No automatic telemetry, no background events, no BLE/GPS/track reading, no persistent token, no cached queue, no retry. It does not assert cloud storage on HTTP success. The app requests an ingestion-only **project token** in its own local UI; never enter a personal API key or share credentials in chat or logs. The user must opt in explicitly per attempt; the checkbox resets after use.

**Single-event contract:** `https://eu.i.posthog.com/i/v0/e/`, event `cm_lab_ping`, synthetic random per-attempt `distinct_id`, `ping_id`, `$process_person_profile=false`. Independent readback in PostHog must match the ping ID and show exactly one accepted row. Do not confuse transport HTTP success with PostHog storage. Device transport/IP is processed by PostHog even though the payload contains no real user data. Existing PostHog project is on Free and anonymizes IP, to be rechecked before field trial. Do not link the per-attempt ID to the public BLE participant ID.

**Installation separation:** `-PconvoyPingLab=true` produces package `com.example.convoy_mesh.pinglab` and label `Convoy Ping LAB`, leaving `com.example.convoy_mesh.pedestrianexp1` untouched. Incremented app version `0.7.7-pinglab+10`. Existing GitHub Android build workflow is hard-bound to the app candidate and will NOT build, certify or publish this new identity automatically. A dedicated reviewed, source-pinned CI build / signature / package / SHA256 receipt is necessary before installation. Do not run the two Convoy packages simultaneously.

**Gate:** code review and local unit tests of `ManualPingService.syntheticEvent` must pass, then CI build and emulator. The physical trial on one phone requires a verified dedicated APK and a fresh readback check of PostHog's event counts. No APK is available from this commit. PR #5's deletion proof and 160-row full synthetic cloud gate remain HOLD and separate; this small manual connectivity event does not prove consent-revocation or deletion of already-ingested data. No release, merge or collected data in this phase.
